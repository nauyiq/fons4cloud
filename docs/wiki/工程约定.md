# 工程约定

以下为依据当前仓库整理的场景化工作建议及已有边界，不把单个实现推广成全库统一规范；修改前仍需检查目标模块、依赖版本和测试。构建与运行入口见 [README](../../README.md) 和 [治理运行准备](../governance.md#本地运行准备)。

| 适用场景 | 推荐入口与边界 | 代表性证据 |
| --- | --- | --- |
| 治理目标接入 | 在现有治理发布流程内接入新目标时，先检查 `GovernanceTargetAdapter` 及已有适配器，保留读取、校验、发布和回滚能力的目标差异。接口存在不代表目标系统一定可回滚。 | [适配器接口](../../fons4cloud-admin/fons4cloud-admin-service/src/main/java/com/fons/cloud/admin/domain/adapter/GovernanceTargetAdapter.java)、[网关路由适配器](../../fons4cloud-admin/fons4cloud-admin-service/src/main/java/com/fons/cloud/admin/infrastructure/nacos/GatewayRouteGovernanceAdapter.java) |
| 治理发布变更 | 保留基线比较、目标回读及失败状态区分，先检查受影响的编排与测试；Mock 测试只覆盖其设定的场景，不证明外部目标实际写入或一致性。 | [发布服务](../../fons4cloud-admin/fons4cloud-admin-service/src/main/java/com/fons/cloud/admin/application/GovernancePublishService.java)、[发布测试](../../fons4cloud-admin/fons4cloud-admin-service/src/test/java/com/fons/cloud/admin/application/GovernancePublishServiceTest.java)、[发布设计](../governance.md#治理发布流程) |
| Admin REST 权限 | 修改受保护的 Admin 端点时检查网关资源权限和内部权限，复用现有注解及权限码。匿名端点和认证控制器有不同边界，以测试和安全配置为准。 | [ChangeController](../../fons4cloud-admin/fons4cloud-admin-service/src/main/java/com/fons/cloud/admin/interfaces/rest/ChangeController.java)、[权限注解边界测试](../../fons4cloud-admin/fons4cloud-admin-service/src/test/java/com/fons/cloud/admin/infrastructure/security/AdminResourceAnnotationBoundaryTest.java) |
| 消息发送或本地事务消息 | 先检查 Stream 接口及目标 MQ 适配；本地消息持久化扩展口本身不提供完整的事务、重试、去重或补偿保证。结合目标中间件和业务场景验证。 | [StreamProducer](../../fons4cloud-common/fons4cloud-common-stream/src/main/java/com/fons/cloud/stream/api/StreamProducer.java)、[本地消息扩展口](../../fons4cloud-mq/fons4cloud-mq-api/src/main/java/com/fons/cloud/mq/api/transactional/service/MqMessageOperations.java)、[消息设计](../messaging.md#本地事务消息路径) |
| 认证接入和验证 | 区分集中授权与 Sa-Token 独立会话，沿对应路径检查配置和测试；内存会话测试不能证明 Redis 或完整网关链路。 | [认证设计](../gateway-auth.md)、[Sa-Token 会话测试](../../fons4cloud-auth/fons4cloud-auth-satoken/src/test/java/com/fons/cloud/auth/satoken/api/SaTokenAuthTemplateTest.java)、[网关权限测试](../../fons4cloud-gateway/src/test/java/com/fons/cloud/gateway/server/auth/AuthorizationManagerTest.java) |
| Admin 前端 API | 修改认证或请求处理时先检查共享客户端与会话处理；登录、刷新、重试和错误分类有不同分支。 | [API 客户端](../../fons4cloud-admin/fons4cloud-admin-ui/src/api/client.ts)、[结果处理](../../fons4cloud-admin/fons4cloud-admin-ui/src/api/result.ts) |

仓库存在不同公共异常及结果类型，尚未核实全局统一选型；应按目标模块现有调用与处理链选择，不据类名推断全库标准。第三方依赖声明不等于已启用或其运行语义已验证。
