## 3. 隔离环境执行前检查

- [ ] environment-name 明确标识为非生产。
- [ ] Nacos namespace/group 与生产隔离，测试 dataId 可清理。
- [ ] Redis key prefix 或 DB 独立，已准备清理命令和责任人。
- [ ] MySQL 指向测试库，已核对当前结构，不自动执行 DDL。
- [ ] auth-service 使用测试 Client Secret 和测试管理员账号。
- [ ] 网关和目标服务允许访问，Actuator 暴露范围符合测试约定。
- [ ] 路由、IP 名单、授权资源、OAuth Client 均使用唯一测试键。
- [ ] 每次发布前记录 baseHash、目标 Hash、快照 ID 和清理动作。
- [ ] 漂移测试只修改测试资源，回滚后再次回读确认。
- [ ] 所有测试资源、Redis 键和临时凭据均完成清理并留证。
