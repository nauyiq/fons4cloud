## 2. 未关闭风险

1. gateway 登录入口未关闭：Nacos 路由已经包含 `admin-service`，但 `POST /admin/auth/login` 经 gateway 返回 HTTP 401、业务码 `400001`；Redis 当前未发现 `GLOBAL_IGNORED_ACCESS_TOKEN_API`，说明登录入口未被 gateway 放入免 token 清单。
2. gateway 受保护接口转发未关闭：直连 admin-service 登录可成功获取 Token，但携带该 Bearer token 调用 `GET /admin/services` 经 gateway 返回 HTTP 403、业务码 `400002`，请求在 gateway 全局权限资源校验阶段被拒绝，尚未进入 admin-service 自有 RBAC。
3. gateway 与 admin-service 权限边界当前结论：gateway 复用 `GLOBAL_AUTHORIZATION_RESOURCE` 只校验 `@AuthenticationResource(authorities = "ADMIN")` 注册的控制面入口权限；admin-service 自有 RBAC 通过 `@AdminPermission` 校验 `{domain}:{action}` 细粒度权限。
4. 真实 Nacos/Redis 写入未在本轮执行：用户已确认真实 Nacos/Redis 写入、发布、漂移验证和清理后续通过前后端集成测试验证，本轮记录为暂缓项。
