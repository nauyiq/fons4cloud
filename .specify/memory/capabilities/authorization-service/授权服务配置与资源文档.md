# 授权服务配置与资源文档

> 文档层级：能力域级
> 能力域名称：授权服务
> 能力域标识：authorization-service
> 文档状态：基线已建立
> 更新日期：2026-06-26

## 1. 配置与资源边界

- 本能力域拥有的配置：auth-service 应用配置、OAuth2 授权服务器配置、Spring Security 配置、Token 存储配置、OAuth Client 数据装配配置、权限资源 Redis key、认证错误消息资源。
- 本能力域依赖的资源：Redis OAuth2Authorization、Redis 权限资源集合、账号数据、OAuth Client 数据、验证码缓存、Dubbo 服务注册、Freemarker 登录/确认页面模板。
- 外部托管资源：Nacos 配置、Redis、数据库、Dubbo 注册中心、验证码发送通道、网关或资源服务。
- 不归属本能力域的配置或资源：网关动态路由、Sentinel 网关流控、业务权限字典治理、生产安全运维制度。

| --- | --- | --- | --- | --- | --- |

```mermaid
flowchart LR
    Caller["调用方"] --> RPC["Dubbo Facade"]
    Caller --> HTTP["OAuth2 /auth 端点"]
    RPC --> AuthApp["AuthenticationApplicationService"]
    HTTP --> AuthServer["Spring Authorization Server"]
    AuthApp --> Account["Account 数据"]
    AuthApp --> Client["OauthClient 数据"]
    AuthServer --> Client
    AuthApp --> Token["OAuth2TokenGenerator"]
    AuthServer --> Token
    Token --> RedisAuth["Redis OAuth2Authorization"]
    Resource["资源服务/网关"] --> Introspector["Opaque Token Introspector"]
    Introspector --> RedisAuth
    Permission["权限校验"] --> RedisResource["Redis 权限资源集合"]
```

| 治理项 | 规则 | 适用对象 | 状态 |
