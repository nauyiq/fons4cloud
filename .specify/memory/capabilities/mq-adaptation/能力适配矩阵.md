## 1. 适配范围

- 技术能力：消息发送、事务消息、动态消息资源初始化、Canal 消息监听转发。
- 适配对象类型：消息中间件、SDK、部署形态。
- 公共能力抽象：`StreamProducer`、`StreamProducerFactory`、`StreamMessage`、`AbstractStreamProducerTemplate`、`MqTransactionalService`、`MqMessageOperations`、`LocalTransactionalMessage`。
- 不得作为标准能力的特定实现：`KafkaProducer`、`RabbitmqProducer`、`RocketmqProducer`、`StreamBridgeProducer`、三类 Provider AutoConfiguration、三类 Canal Listener、动态 Topic/Queue 初始化器。

## 3. 标准能力判定

| 结论 | 依据 | 适用范围 | 限制 |
| --- | --- | --- | --- |
| `StreamProducer`、`StreamMessage`、`AbstractStreamProducerTemplate` 可作为消息发送标准骨架。 | 公共接口和抽象模板，且 Kafka/Rabbit/Rocket Producer 均继承或依赖该骨架。 | 消息发送抽象。 | Provider 特定消息对象和资源模型不属于标准。 |
| `MqTransactionalService`、`MqMessageOperations`、`LocalTransactionalMessage` 可作为事务消息标准骨架。 | 公共 API 和 Kafka/Rabbit 事务服务实现继承该骨架。 | 保存本地事务消息后同步发送 MQ。 | 本地消息表结构、补偿调度和确认策略未确认。 |
| Kafka、RabbitMQ、RocketMQ 的 Producer 发送步骤不能作为全局标准。 | 三类实现依赖不同客户端、消息模型和资源模型。 | Provider 适配说明。 | 只能标记为特定能力适配。 |
| Canal 消息监听转发不是新的 MQ Provider。 | Kafka/Rabbit/Rocket 均调用 `CanalGlue`，核心解析能力属于 `common-canal`。 | MQ 监听转发场景。 | Canal 解析规则需另行建模。 |
