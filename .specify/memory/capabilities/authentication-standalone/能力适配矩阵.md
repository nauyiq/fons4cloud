# 能力适配矩阵

> 文档层级：能力域适配索引
> 能力域名称：独立认证
> 能力域标识：authentication-standalone
> 文档状态：基线已建立
> 更新日期：2026-07-31

## 1. 适配范围

- 技术能力：登录认证、会话校验、令牌管理（登出/踢人/查询）、会话持久化、路由拦截鉴权、权限/角色注解接入。
- 适配对象类型：认证 SDK、存储实现、令牌传递方式。
- 公共能力抽象：`SaTokenAuthTemplate`（登录/会话/踢人工具入口）、`SaTokenWebMvcConfigurer` + `FonsSaTokenProperties`（路由拦截+白名单配置骨架）、`StpInterface`（权限/角色接入契约）。
- 不得作为标准能力的特定实现：Sa-Token 1.45.0 SDK、`sa-token-redis-jackson` 会话 Redis 持久化、Header+Cookie 双令牌传递、`DefaultStpInterfaceImpl` 空权限实现。

## 3. 标准能力判定

| 结论 | 依据 | 适用范围 | 限制 |
| --- | --- | --- | --- |
| `SaTokenAuthTemplate` 可作为独立认证的标准工具入口。 | 封装登录/登出/会话校验/踢人/令牌查询，业务方注入即用。 | 全部独立认证场景。 | 具体登录凭证校验由业务方完成。 |
| `SaTokenWebMvcConfigurer` + `FonsSaTokenProperties` 可作为路由拦截与白名单标准配置骨架。 | 注册 `SaInterceptor` 并按 `sys.sa-token.*` 配置放行。 | WebMVC 环境独立认证。 | 不适用于 WebFlux 响应式环境。 |
| `StpInterface` 可作为权限/角色数据接入标准契约。 | Sa-Token 框架契约，业务方实现后启用注解鉴权。 | 全部注解鉴权场景。 | 默认空实现不提供任何权限/角色。 |
| Sa-Token 1.45.0 SDK 是当前唯一适配实现，不作为唯一标准。 | 当前只有一种 SDK 适配，无横向对比。 | 当前实现。 | 后续若引入 JWT/SSO/其他 SDK 再拆分适配说明。 |
