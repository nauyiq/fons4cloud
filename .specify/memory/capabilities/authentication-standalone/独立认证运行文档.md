# 独立认证运行文档

> 文档层级：能力域级
> 能力域名称：独立认证
> 能力域标识：authentication-standalone
> 文档状态：基线已建立
> 更新日期：2026-07-31

## 1. 运行职责边界

- 入口/API/任务：业务 Controller 调用 `SaTokenAuthTemplate`；HTTP 请求经 `SaInterceptor` 路由拦截；注解鉴权经 Sa-Token AOP 切面。
- 编排组件：`FonsSaTokenAutoConfiguration`（装配三件套）、`SaTokenWebMvcConfigurer`（注册拦截器）。
- 适配组件：`sa-token-redis-jackson`（会话 Redis 持久化）、`DefaultStpInterfaceImpl`（权限空实现）。
- 外部依赖：Redis（经 `fons4cloud-common-cache` 的 `RedisConnectionFactory`）、Spring Boot WebMVC 容器。
- 不属于本能力域的运行职责：网关 Token 内省、Dubbo RPC 认证调用、OAuth2 授权服务器流程、账号数据持久化、验证码发送。

## 3. 核心调用时序

### 3.1 登录时序

```mermaid
sequenceDiagram
    participant A as 业务 Controller
    participant B as SaTokenAuthTemplate
    participant C as StpUtil (Sa-Token)
    participant D as sa-token-redis-jackson
    participant E as Redis (common-cache)
    A->>B: login(loginId)
    B->>C: StpUtil.login(loginId)
    C->>D: setTokenValue / saveSession
    D->>E: SET satoken:* (JSON)
    E-->>D: OK
    D-->>C: 完成
    C-->>B: token 已生成
    B-->>A: 返回
```

### 3.2 路由拦截校验时序

```mermaid
sequenceDiagram
    participant A as HTTP 请求
    participant B as SaInterceptor
    participant C as StpUtil (Sa-Token)
    participant D as sa-token-redis-jackson
    participant E as Redis (common-cache)
    A->>B: 请求命中拦截路径
    B->>C: checkLogin (globalLoginCheck=true)
    C->>D: getTokenValue / getLoginId
    D->>E: GET satoken:*
    E-->>D: token 数据
    D-->>C: 登录态
    alt 已登录
        C-->>B: 放行
        B-->>A: 继续执行
    else 未登录
        C-->>B: 抛 NotLoginException
        B-->>A: 异常响应
    end
```

图示状态：已根据 `SaTokenAuthTemplate`、`SaTokenWebMvcConfigurer` 源码与单元测试补全。
