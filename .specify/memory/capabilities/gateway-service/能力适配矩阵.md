# 能力适配矩阵

> 文档层级：能力域适配索引
> 能力域名称：网关服务
> 能力域标识：gateway-service
> 文档状态：基线已建立
> 更新日期：2026-06-26

## 1. 适配范围

- 技术能力：统一入口转发、动态路由、资源服务器鉴权、认证用户透传、请求包装、HTTP 节流风控、Sentinel 网关流控响应、验证码入口。
- 适配对象类型：配置源、认证方式、过滤器扩展、流控实现、缓存资源、响应处理。
- 公共能力抽象：`RouteDefinitionRepository`、`DynamicRouteConfigProperties`、`SecurityWebFilterChain`、`ReactiveOpaqueTokenIntrospector`、`AuthorizationManager`、`AuthPermissionService`、`GlobalFilter`、`Ordered`、`HttpThrottles`、`ThrottlesServer`、`BlockRequestHandler`、`RouterFunction`。
- 不得作为标准能力的特定实现：Nacos 路由配置源、Redis Token/验证码/黑名单存储、Sentinel Gateway 当前接入形态、Hutool Captcha 验证码生成、当前 `gateway-routing.json` 和 `gateway-sentinel-flow` 配置样例。

## 3. 标准能力判定

| 结论 | 依据 | 适用范围 | 限制 |
| --- | --- | --- | --- |
| Gateway 动态路由标准骨架是 `RouteDefinitionRepository` 与配置模型，不是 Nacos 本身。 | Spring Cloud Gateway 契约和 `NacosRouteDefinitionRepository` 实现。 | 后续扩展其他配置源。 | Nacos 只能作为当前代表性实现。 |
| 网关鉴权标准骨架是 WebFlux Resource Server、Opaque Token 内省和权限 Facade 调用。 | `ResourceServerConfiguration`、`AuthorizationManager`、授权服务能力文档。 | 网关受保护请求。 | Token 生命周期仍归授权服务。 |
| 用户透传可作为网关运行骨架，但具体 `AUTH_USER` 格式是当前实现。 | `SecurityAuthenticationFilter`。 | 下游服务识别用户。 | Header 格式和防篡改策略需后续确认。 |
| 自定义 HTTP 节流标准骨架是 `HttpThrottles` 和 `ThrottlesServer`，当前 Redis 黑白名单和攻击词是实现。 | `GatewayHttpThrottles`、`ThrottlesProcess`。 | 网关请求风控。 | 具体阈值和策略不在网关能力中定义。 |
| Sentinel block 响应处理可作为接入点，当前不能写成完整 Sentinel 执行链路标准。 | `SentinelGatewayConfiguration`、`application.yml`。 | Sentinel Gateway 限流响应。 | 过滤器启用来源和规则治理待确认。 |
